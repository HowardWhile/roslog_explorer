# ROS Log Explorer

[線上開啟 ROS Log Explorer](https://howardwhile.github.io/roslog_explorer/)

在瀏覽器中分析 ROS 2 MCAP 檔案的 `/rosout` 紀錄。拖入檔案後，即可依訊息內容、Logger、等級與時間範圍找出需要追查的事件，再將篩選結果匯出為 CSV。

**不需要安裝套件或上傳檔案。** 檔案由瀏覽器在本機讀取與處理。

## 快速開始

1. 開啟 [rosout.html](./rosout.html)。
2. 點選載入區選擇一個或多個 `.mcap` 檔，或將檔案、資料夾拖入頁面。
3. 載入完成後，在紀錄列表查看結果；用搜尋條件、Log 等級或時間分布縮小範圍。
4. 按「下載結果 CSV」取得符合目前條件的全部紀錄。

頁面右上角可切換繁體中文／英文與明暗主題。時間分布會在載入紀錄後展開。

## 適合用來做什麼

- **快速定位異常：** 在時間分布中查看 WARN 與 ERROR／FATAL 出現的時段，再拖曳選取時間範圍。
- **追查訊息來源：** 搜尋 Logger 名稱、訊息文字、來源檔案、函式或 MCAP 檔名；表格也會顯示來源行號。
- **合併檢視多個檔案：** 一次載入多個 MCAP，依時間排序，並保留每筆紀錄所屬的 MCAP 名稱。
- **分享分析結果：** 匯出目前篩選後的 CSV，供試算表或其他工具繼續處理。

## 搜尋與篩選

在搜尋框輸入文字並按 **Enter**，即可新增一個搜尋標籤。輸入 Logger 名稱時，頁面會提供建議。點選標籤可編輯，點選旁邊的 × 可移除。

| 輸入 | 效果 |
| --- | --- |
| `robot_driver` | 一般標籤；多個一般標籤都必須符合 |
| `+taskmgr` | 額外納入符合此標籤的紀錄 |
| `-heartbeat` | 排除符合此標籤的紀錄 |

例如，`robot_driver` 與 `+taskmgr` 會顯示符合其中任一條件的紀錄；再加入 `-heartbeat`，就會排除包含 `heartbeat` 的紀錄。搜尋不區分大小寫，會比對等級、Logger、訊息、來源檔案、函式與 MCAP 檔名。

「Log 等級」可設定最低顯示等級。時間軸可拖曳選取範圍；若需要精確時間，展開「進階時間設定」輸入開始與結束時間。按「清除時間範圍」可回到完整時段。

## 支援範圍與限制

- 讀取副檔名為 `.mcap`、具有索引的 MCAP 檔案。
- 目標 topic 為 `/rosout`，訊息需使用 CDR 編碼，schema 名稱需包含 `rcl_interfaces/msg/Log`。
- 目前沒有提供壓縮資料區塊的解壓處理；若檔案使用不受支援的壓縮格式，頁面會顯示讀取錯誤。
- 表格最多顯示前 **5,000 筆**符合條件的紀錄；CSV 會包含**全部**符合條件的紀錄。
- 資料夾拖放取決於瀏覽器對資料夾讀取 API 的支援。如果無法讀取資料夾，可改為直接選取或拖入 MCAP 檔案。

## 常見問題

### 載入後沒有紀錄？

確認 MCAP 內含 `/rosout` topic，且訊息格式符合上方支援範圍。頁面會在「讀取狀態」或錯誤訊息中顯示各檔案的問題。

### 為什麼 CSV 比表格多？

表格為了保持操作順暢，只呈現前 5,000 筆；下載會依目前搜尋、等級與時間條件匯出所有符合的紀錄。CSV 欄位包含時間、等級、Logger、訊息、MCAP、來源檔案、函式與行號。

### 檔案會送到伺服器嗎？

此頁面從本機選取的檔案在瀏覽器內解析；程式本身沒有上傳流程。
